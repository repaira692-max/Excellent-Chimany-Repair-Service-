# Chimney Repair Home Service Website

This is a responsive, mobile-friendly static website starter for chimney repair and home service.

## Included files
- `index.html` — website content, SEO metadata, service-area schema, booking form
- `style.css` — responsive design and styling
- `script.js` — mobile menu and WhatsApp booking form
- `assets/` — reserved folder for your own photos/logo if you add them later

## Upload to GitHub Pages (Hindi instructions)
1. ZIP file ko extract/unzip karein.
2. GitHub par login karke **New repository** banayein, example `chimney-repair-website`.
3. Repository ke andar **Add file → Upload files** par click karein.
4. Extract ki hui folder ke ANDAR ki files (`index.html`, `style.css`, `script.js`, `assets` folder) upload karein. ZIP ko directly upload na karein.
5. **Commit changes** dabayein.
6. Repository mein **Settings → Pages** kholein.
7. **Deploy from a branch** select karein; branch `main`, folder `/(root)` select karke Save karein.
8. GitHub jo website URL dega, use open karke mobile aur desktop par check karein.
9. Apne domain ko connect karne ke liye domain provider aur GitHub Pages ke DNS settings mein custom domain set karna hoga. DNS badalne se pehle domain ka current setup note kar lein.

## Domain caution
The canonical URL currently uses `https://www.kitchenmaster360.in/` because it was supplied as the reference URL. If you deploy to your own domain, change the canonical URL and Open Graph URL to your own domain in `index.html`. Do not publish a website on a domain you do not own or control.

## SEO notes
The site includes a page title, meta description, heading hierarchy, local service-area copy, and HomeAndConstructionBusiness structured data. SEO rankings are not guaranteed; Google needs time to crawl/index the site and rankings depend on many factors.
