GitHub par upload karne ka tarika:
1. ZIP file ko phone/computer mein extract karein.
2. github.com par login karein aur New repository banayein.
3. Extract kiye hue folder ke andar se index.html, style.css agar ho, script.js agar ho, README-HINDI.txt aur assets folder ko repository ke root mein upload karein. Is package mein CSS/JS index.html ke andar hi hai.
4. Commit changes karein.
5. Repository Settings > Pages mein jaakar Deploy from a branch choose karein; branch main aur folder /(root) select karein, phir Save.
6. GitHub Pages URL par website check karein.

Apne domain par lagane ke liye:
- Aapka domain provider aur hosting alag se set karna hoga. Domain ka exact naam aur hosting provider batayein to DNS steps diye ja sakte hain.
